import {SeerOutOfCreditsCta} from 'sentry/components/seer/outOfCredits/seerOutOfCreditsCta';
import {SeerOutOfCreditsNotice} from 'sentry/components/seer/outOfCredits/seerOutOfCreditsNotice';
import * as Storybook from 'sentry/stories';

Product code renders `SeerOutOfCreditsCta`, which getsentry fills in: it picks
the escalation from the viewer's billing access and whether the org can
self-serve. Open source has no credits and renders nothing. These demos render
the `SeerOutOfCreditsNotice` underneath it.

```jsx
<SeerOutOfCreditsCta />
<SeerOutOfCreditsCta message={t('Seer stopped because your organization ran out of credits.')} />
```

## Billing members

Members with `org:billing` top up themselves. "Top up" opens the Seer credits
modal in place, with the balance and the auto top-up settings.

<Storybook.Demo>
  <SeerOutOfCreditsNotice escalation="top-up" onTopUp={() => {}} />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice escalation="top-up" onTopUp={openTopUpModal} />
```

## Everyone else

Members without billing access ask the billing members to add credits. Sending
the request shows a toast.

<Storybook.Demo>
  <SeerOutOfCreditsNotice escalation="request" onRequestCredits={() => {}} />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice escalation="request" onRequestCredits={handleRequestCredits} />
```

## Request sending

<Storybook.Demo>
  <SeerOutOfCreditsNotice
    escalation="request"
    onRequestCredits={() => {}}
    isRequestingCredits
  />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice

/>
```

## Orgs that can't self-serve

Orgs that buy through an account team get no request button.

<Storybook.Demo>
  <SeerOutOfCreditsNotice escalation="contact" />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice escalation="contact" />
```

## Custom message

Pass `message` to replace the headline, for example when a run already stopped
part way because it ran out.

<Storybook.Demo>
  <SeerOutOfCreditsNotice
    escalation="top-up"
    onTopUp={() => {}}
    message="Seer stopped because your organization ran out of credits."
  />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsNotice
  escalation="top-up"
  onTopUp={openTopUpModal}
  message={t('Seer stopped because your organization ran out of credits.')}
/>
```

## For the signed-in viewer

`SeerOutOfCreditsCta` itself, with the escalation getsentry picks for you. In
getsentry, "Top up" and "Request credits" do the real thing: the modal reads and
saves your org's Seer wallet, and the request emails your billing members. Open
source renders nothing here.

<Storybook.Demo>
  <SeerOutOfCreditsCta />
</Storybook.Demo>

```jsx
<SeerOutOfCreditsCta />
```
